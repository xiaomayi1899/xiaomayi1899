# 双色球 · 大乐透 公式投票选号

手机在线工具：8 式独立科学公式 × 投票制合成推荐 × 开奖后自动同步数据并复盘。

## 在线使用

仓库 Pages 开启后访问：`https://xiaomayi1899.github.io/xiaomayi1899/`

- 🔴 双色球 / 🔵 大乐透：各自 11 式独立公式（两彩种零共享，不同号码池/窗口/统计口径）
- 🗳 投票制：每式产出 1 注并对号码计票，票数最高者组成推荐号
- 📋 复盘：每期用「开奖前可得数据」确定性重算当时推荐并对照实际，无事后拟合
- 🔄 自动更新：GitHub Actions 每日 21:35 / 22:05 / 次日 09:30（北京时间）抓取官方开奖并提交

## 11 式方法体系（每式一个独立科学方法，无冗余）

| 双色球 | 大乐透（独立实现） |
| --- | --- |
| 贝叶斯频率式（30期证据+100期先验收缩） | 后验优势式（20期证据+120期先验） |
| 和值密度式（正态近似 μ±0.4σ） | 和值通道式（20期回归通道动态中心） |
| 奇偶形态式（众数结构匹配） | 奇偶动力学式（众数动量定窗） |
| 质合形态式（质数枚数众数约束） | 质数结构式（60期窗口质数枚数） |
| 遗漏危险率式（遗漏÷平均间隔） | 周期相位式（遗漏÷中位间隔） |
| 马尔可夫承接式（转移矩阵+邻号） | 同尾转移式（全转移+同尾+邻号三矩阵） |
| 覆盖设计式（三区2:2:2+尾数覆盖≥5） | 区间覆盖式（12/12/11 三区2:2:1+尾数≥4） |
| 心理冷门式（反热门·期望分成博弈） | 反热门博弈式（独立热门度表） |
| 趋势残差式（logistic 趋势 MLE 的 Pearson 残差） | 趋势得分式（Cochran–Armitage 趋势检验 z 分数） |
| 反共现式（共现网络稀疏化，最小化组内两两共现） | 雅卡尔反共现式（归一化共现相似度稀疏化） |
| 模型平均式（三模型 walk-forward 对数打分的证据加权 BMA） | 跨区条件式（前区和值三分位→后区奇偶的滞后条件众数） |

## 数据管道

```
scripts/fetch_update.py
  ├─ 官方源：cwl.gov.cn（双色球，Referer 校验）、sporttery.cn（大乐透）
  ├─ 兜底源：textdb.dev 镜像频道
  └─ 合并历史 → data/ssq.json、data/dlt.json（仅变化时写盘）
GitHub Actions → commit → GitHub Pages → 页面打开自动加载
```

页面端三级数据链：同源 JSON（权威）→ localStorage 缓存（离线可用）→ textdb 镜像（只补新期号）。

## 免责声明

彩票每期开奖为独立随机事件，任何统计公式都不能提高中奖概率。「心理冷门/反热门」式的价值仅在于中奖概率不变的前提下降低与他人重号概率（期望分成更高）。复盘命中波动属正常随机现象。请理性购彩，量力而行。
