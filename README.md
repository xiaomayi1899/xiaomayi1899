# 双色球 · 大乐透 公式投票选号（可量化 · 一票制）

手机在线工具：**15 式独立科学公式 × 每式 1 票委员会合成 × 统一量化评估（Brier/BSS/z 检验）× 开奖后自动同步数据并复盘**。

## 在线使用

仓库 Pages 开启后访问：`https://xiaomayi1899.github.io/xiaomayi1899/`

- 🔴 双色球 / 🔵 大乐透：各自 15 式独立公式（两彩种零共享，不同号码池/窗口/统计口径）
- 🗳 **一票制合成**：每式只举 1 个主区号（其主驱动分数的 argmax）+ 1 个蓝球/后区号 → 主区 15 票选 6 席（双色球）/ 5 席（大乐透）、后区 15 票选 2 席；排序 = 票数 → 信念强度(Σp) → Borda 积分 → 号码升序；页面明示每号票源与「与上期重合度」
- 🧮 **Borda 计分注**与**多注参考**（3 注，注间主区重叠≤2）并列对照
- 📋 复盘：每期用「开奖前可得数据」确定性重算当时推荐并对照实际，无事后拟合；窗口可选 **15/30/50/100 期**，附 95% 置信区间与 z 检验（合成注=超几何、单式票=二项）
- 📈 量化：15 式在同一把尺子下横评——Brier 分数、BSS、对数得分技巧分、命中分布直方图、Bonferroni 校正（30 次比较）显著性、自适应加权 Borda 注、概率透镜（精确奖级概率+期望回报）、资金纪律（凯利视角）
- 🔄 自动更新：GitHub Actions 每日 21:35 / 22:05 / 次日 09:30（北京时间）抓取官方开奖并提交

## 统一量化口径（2026e1）

每式的主驱动分数 → 组内 z 标准化 → log-linear 倾斜 `p(n)=p₀·e^{0.35z}` → 校准 Σp=k（红 6/蓝 1，前 5/后 2）。该变换对分数单调，不改变任何一式的选号/投票结果，只把「选号」升级为「可评分的预测分布」：

- **Brier / BSS**：均方概率误差与技巧分（1 − Brier/Brier₀），BSS>0 表示比瞎猜准；
- **对数得分技巧分**：平均对数似然之差（nats/号·期）；
- **命中 z 检验**：合成注对超几何零模型、单式票对二项零模型；|z|≥3.13 为 30 次比较 Bonferroni 校正后的显著性门槛；
- **自适应加权**：w_i ∝ exp(6·n·skill/(n+40))，样本越小权重越被压平至均匀 1/15（正则化防过拟合）；
- **诚实预期**：独立随机数据下所有式 BSS≈0、z≈0——量化层的价值是**用数据公开证实这一点**。

评估层（组合数/超几何矩/Brier/对数得分/威尔逊区间/正态 p 值）为两引擎共用的纯数学量尺，不含任何选号逻辑；两彩种选号逻辑仍保持零共享。

## 数据管道

```
scripts/fetch_update.py
  ├─ 官方源：cwl.gov.cn（双色球，Referer 校验）、sporttery.cn（大乐透）
  ├─ 兜底源：textdb.dev 镜像频道
  └─ 合并历史 → data/ssq.json、data/dlt.json（仅变化时写盘）
GitHub Actions → commit → GitHub Pages → 页面打开自动加载
scripts/push_github.ps1（本地/AutoClaw 经 contents API 推送）
```

页面端三级数据链：同源 JSON（权威）→ localStorage 缓存（离线可用）→ textdb 镜像（只补新期号）。

测试：`node tests/test_engine.js`（从构建产物提取引擎，379 项断言：确定性、校准性、一票制结构、多注约束、恒等式、耗时）。

## 免责声明

彩票每期开奖为独立随机事件，任何统计公式都不能提高中奖概率。「心理冷门/反热门」式的价值仅在于中奖概率不变的前提下降低与他人重号概率（期望分成更高）。相邻期推荐重合度高属确定性引擎的正常表现（数据仅增加一期）。复盘命中波动属正常随机现象；量化指标若短期显著，优先怀疑运气与多重比较。请理性购彩，量力而行；未满 18 周岁不得购彩。
